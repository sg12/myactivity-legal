Common questions

  • How do I log something quickly? Tap a saved template on the calendar screen, or the + button for anything else — see Settings → Manage templates to save your regular sessions.
  • Can I add my own sport? Yes — Settings → Manage categories → + lets you name a category and pick an icon for it.
  • Where's my data backed up? Settings → Export data shares a JSON backup you control; Import data restores from one. There's no automatic cloud sync — see our Privacy Policy for why.
  • Does this app need internet? No — MyActivity works fully offline. Apple Health is the only optional network-adjacent feature, and it's off unless you turn it on.
